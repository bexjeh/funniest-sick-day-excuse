One line under 200 characters that gets you out of work and gets a laugh — an entry for make.fun's "The Funniest Sick-Day Excuse" bounty. `main.py` writes the excuse, deterministically, to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
